# Word choices

This list shows common words and phrases to replace with simpler ones. It is a guide, not a strict dictionary. If a word is the clearest choice for the reader, use it.

## Replace long words with short words

| Instead of | Write |
|---|---|
| approximately | about |
| assist | help |
| commence | start |
| demonstrate | show |
| endeavor | try |
| facilitate | help, make possible |
| implement | do, use, add |
| indicate | show |
| modify | change |
| numerous | many |
| obtain | get |
| prior to | before |
| purchase | buy |
| require | need |
| subsequently | then, after |
| sufficient | enough |
| terminate | stop, end |
| utilize | use |

## Replace wordy phrases with one or two words

| Instead of | Write |
|---|---|
| at this point in time | now |
| due to the fact that | because |
| in order to | to |
| in the event that | if |
| is able to | can |
| make a decision | decide |
| perform an inspection of | inspect, examine |
| take into consideration | think about |
| with regard to | about |

## Replace phrasal verbs with single verbs

| Instead of | Write |
|---|---|
| figure out | find, calculate |
| look into | examine |
| put off | delay |
| set up | install, prepare |
| turn up (volume) | increase |
| carry out | do |

Some phrasal verbs are the normal technical name for an action, such as "log in" or "back up." Keep those.

## Words with more than one meaning

Choose a word that has only one meaning in context.

| Avoid | Problem | Write instead |
|---|---|---|
| since | can mean "because" or "from that time" | because / after |
| as | can mean "because," "while," or "like" | because / when / like |
| check | can mean "examine" or "make sure" | examine / make sure |
| right | can mean "correct" or a direction | correct / right side |
| fine | can mean "good" or "thin" | good / thin |
